# CyberSentinel — Network Security Analytics & SOC Dashboard

CyberSentinel is a simulation-based network security analytics project built with Python, pandas, scikit-learn, SQLite, Streamlit, and Plotly.

It demonstrates a workflow for generating simulated network traffic, identifying suspicious behaviour with rule-based detection and an Isolation Forest anomaly detector, evaluating predictions, storing results, and exploring them through a Security Operations Center (SOC) dashboard.

> **Scope:** This project currently analyzes simulated traffic. It is not a live network monitoring product and does not ingest real-time packets.

## Features

- Simulated network-event dataset with normal and attack-labelled events.
- Rule-based detection demonstrations for port scans, brute-force attempts, traffic flooding, and DNS anomalies.
- Behavioural feature engineering using per-minute traffic statistics.
- Isolation Forest anomaly detection trained using normal training traffic.
- Held-out evaluation comparing ML predictions with rule-based predictions.
- SQLite storage for network events, alerts, evaluation metrics, and ML predictions.
- Streamlit SOC dashboard with:
  - Security Overview
  - Network Analytics
  - Threat Intelligence
  - IP Investigation
  - Security Alerts
  - Detection Performance
  - Machine Learning Analytics

## Reported experiment

On the project's held-out simulated test set of 1,958 events, the behavioural Isolation Forest experiment reported:

| Metric | Behavioural Isolation Forest | Rule-based detection |
|---|---:|---:|
| Accuracy | 98.11% | 96.88% |
| Precision | 92.24% | 87.82% |
| Recall | 100.00% | 100.00% |
| F1 score | 95.97% | 93.52% |
| False positives | 37 | 61 |

These are results from this specific simulated dataset and split. They should not be interpreted as expected performance on real network traffic. The evaluation uses simulation ground-truth labels and the feature design reflects the simulated attack patterns.

- `requirements.txt` — Python dependencies.
- `assets/` — Dashboard screenshots.

**Notebook note:** Add your Google Colab notebook (`.ipynb`) to this repository after downloading it from Colab using **File → Download → Download .ipynb**. The notebook contains the simulation, feature engineering, model training, evaluation, and database preparation workflow.

**Database note:** The SQLite database (`cybersentinel.db`) is generated by the notebook and is intentionally not included in this starter package. Run the notebook's database creation/storage cells before launching the dashboard.

## Run locally

1. Clone or download this repository.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the notebook to generate `cybersentinel.db` and populate the required tables.
4. Place `cybersentinel.db` in the same directory as `app.py`.
5. Start the dashboard:

   ```bash
   streamlit run app.py
   ```

## Required SQLite tables

The dashboard reads these tables:

- `network_events_v2`
- `security_alerts_v2`
- `evaluation_metrics`
- `ml_predictions_v3`
- `ml_model_metrics_v3`

The final two tables are created by the ML-results storage cell in the notebook.

## Limitations and future work

- The current dataset is simulated; live traffic capture is not implemented.
- Detection quality on simulated patterns does not establish real-world detection performance.
- Future work could include testing on independently sourced, appropriately authorized datasets, improving generalization, adding model/version tracking, and implementing optional live monitoring in a separate phase.
